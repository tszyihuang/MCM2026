# docs 索引

本目录存放建模说明、求解器解法、模拟器说明与验收报告。
工程里每题只有一条策略（问题3 = `sweeper`，问题4 = `sweeper4`），
文档不再区分"版本"或"路线"。

---

## 1. 按主题索引

| 文件 | 属于 | 内容 |
| --- | --- | --- |
| **`问题3解题思路.md`** | 问题3 | 解题思路（简要）：题目要求、问题本质、核心洞察「清除即探测」、模型框架、关键机制、结果、复现命令 |
| **`问题4解法.md`** | 问题4 | 解法唯一入口：24 点集合覆盖补扫 + 沿示向度射线盲清 + 贴边补扫环；参数档位、2500 局零遗漏实测、复现 |
| `论文_问题4_集合覆盖路线.md` | 问题4 | 问题4 的论文成稿 |
| `模拟器设计说明.md` | 两题 | 模拟器逐条对照题目正文与附件的实现口径、需自行假设的部分 |
| `模拟器使用说明.md` | 两题 | 命令行参数、与附件2 的对应关系、测试与验收命令 |
