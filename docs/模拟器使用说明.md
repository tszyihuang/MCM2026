# 无线电干扰源环境模拟器 · 使用说明

本目录是 2026 年高教社杯全国大学生数学建模竞赛 **B 题「无线电干扰源的快速自动定位与清除」**
配套的**自建模拟器复现版**。它严格按照题目正文、附件1《模拟器使用说明》和
附件2《模拟器通信接口说明及编程指南》实现，可在本地复现题目要求的全部测试流程：

* 目标区域与干扰源物理规则（半径 1800 m 圆域、有效接收半径 1000~1500 m、全向/定向覆盖角）；
* 四条 HTTP+JSON 指令 `/enter`、`/measure`、`/clear`、`/exit` 与全部错误语义；
* 虚拟时钟（移动 / 频道切换 / 检测 / 精确清除耗时）与现实限时（25 分钟窗口 + 20 分钟程序运行）；
* 「问题3 演练 / 问题4 演练 / 问题3 正式 / 问题4 正式」四个测试模块；
* 5 秒倒计时、接口开放、测试案例编码、行为日志（正式测试加密导出，< 2 MB）。

## 2. 快速开始

```powershell
# 1) 启动模拟器（默认机器狗接口 2026，界面 2027）
python -m simulator --team-id <参赛队号>

# 2) 浏览器打开界面，选择测试模块并确认开始
start http://127.0.0.1:2027/

# 3) 倒计时结束、界面显示「接口已就绪」后运行机器狗程序
python -m robotdog.solver.deploy --problem 3   # 全向源 (sweeper)
python -m robotdog.solver.deploy --problem 4   # 含定向源 (sweeper4)
```

也可以让模拟器直接拉起机器狗程序（便于自动化演练）：

```powershell
python -m simulator --team-id <参赛队号> --auto-practice 3 --robot "python -m robotdog.solver.deploy"
```

### 5.1 并发行为（附件2 表2）

模拟器内置串行闸门：同一时刻只允许一个动作在引擎内执行。

* 机器狗**并发发送不同动作** → 被拒的动作返回 HTTP 409 且 `accepted=false`、`virtual_time_s=0`；
* **网络重试**必须复用原 `request_id` 与请求内容，模拟器会等待在途动作结束后按幂等规则
  返回首次响应，不重复移动、检测、清除或推进时间；
* 可用 `SimulatorServer.concurrency_stats()` 查看 `engine_max_concurrent`
  （恒为 1 表示机器狗程序确实是串行发送的）。

## 6. 说明与限制

* 本模拟器是**自建复现版**，用于在本地演练、验证策略与生成对照数据；
  竞赛正式测试仍须使用官方模拟器（附件1 第 4 节下载地址）完成并导出官方加密日志。
* 脱机模式下不会联网注册/登录，仅做本地参赛队号校验；如需与竞赛服务器交互，
  使用 `--login-mode online --login-server <地址>`。
* 干扰源位置、有效接收半径、定向方向的随机分布题目未给出具体形式，
  本实现采用：圆域内均匀分布、半径 `U(1000,1500)`、频道 `1..20` 无重复等概率抽样、
  问题4 中每个干扰源以 1/2 概率为定向源且定向方向 `U(0°,360°)`。
* 「消除全部干扰源」在本问题参数下受现实时间约束限制，详见
  `docs/验收报告.md` 第 4 节的上界分析。
